## Download Instructions

To download all images for local use:

1. **Create an images directory:**
   ```bash
   mkdir images
   ```

2. **Download each image using curl or wget:**
   ```bash
   # Example:
   curl -o images/halle-logo.png "https://www.figma.com/api/mcp/asset/74e77316-9a26-4692-b2de-e08a243cda0c"
   ```

3. **Update image paths in index.html:**
   - Find: `src="https://www.figma.com/api/mcp/asset/..."`
   - Replace with: `src="images/[filename]"`

4. **Optimize images:**
   - Compress JPEGs (70-85% quality)
   - Convert to WebP for better performance
   - Create responsive image sizes

## Recommended Image Optimization

```bash
# Install imagemagick
brew install imagemagick

# Convert and optimize
convert input.jpg -quality 80 -resize 1280x output.jpg
convert input.jpg -quality 80 output.webp
```
